# NebulaSAB

Interface moderne fullstack pour remplacer SABnzbd.

## Stack

- React
- TypeScript
- Vite
- TailwindCSS
- Zustand
- React Query
- Express
- Socket.IO
- Docker

## Démarrage

### Backend

```bash
cd backend
npm install
npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
